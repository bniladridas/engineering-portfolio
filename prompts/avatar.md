# Avatar Prompt

Profile photo / avatar, square, minimum 400 × 400 px (export at 2x).

## Prompt

> Minimal flat vector portrait. Calm, friendly, professional software engineer. Solid white background. Black and grey geometric line work, a single muted-green accent in the clothing or a subtle green rim-light. Clean shapes, no photorealism, generous negative space, consistent with a flat vector illustration style.

## Negative prompt

> photorealistic, 3D render, glossy, busy background, more than one accent color, gradients, drop shadows, text artifacts, watermark.

## Guidance

- If generating a fictional portrait, be transparent about it in the profile.
- A real photo is preferred for trust; the vector style is the fallback for a consistent flat aesthetic.
- Keep the same white background as the banner so the two read as a set.
