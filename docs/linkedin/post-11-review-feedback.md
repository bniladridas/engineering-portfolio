The best feedback I ever got arrived in a way that felt, at first, like an attack.

A maintainer tore apart my pull request with line-level comments. I closed my laptop. The next morning I reread them and realized: every single comment was about the code. None of it was about me.

That is the entire skill of giving feedback:

- Point at the line.
- Suggest the alternative.
- Say why.

"Use the helper here instead: it already handles the null case." That's it. It's concrete, kind, and specific.

Feedback that reads like this grows people and ships better code. Feedback that judges ("this is sloppy," "you didn't think this through") grows defensiveness.

I've stolen that format for every review I write since.

The person whose code you're reviewing isn't your opponent. They're the person you're about to make better.
