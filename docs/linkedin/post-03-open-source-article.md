My first open source review came back with more comments than lines.

It stung. Then I reread it and realized every comment was about the code, not about me. "This branch isn't reachable." "Can this fail?" "Naming."

That separation (code from self) is the most valuable habit open source gave me.

My latest article, *Lessons From Open Source*, covers what the process actually taught me:

- Maintainers are translators, not gatekeepers. Translate, don't gatekeep.
- The projects that thrive treat strangers' time as scarce and precious.
- Contribute to software you actually use. Fix the bug that annoys you.

The code I contribute matters. The practice matters more.
