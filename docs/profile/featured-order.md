# Featured Order

The featured section reads top-down. The first card sets the tone; the last card should round out the story.

1. **Article — Building Software That Lasts.** The thesis of the profile. Sets expectations for everything below.
2. **Project — Palmshed.** A concrete, inspectable example of building in public. Shows the "developer tools" claim with an actual tool.
3. **Best repository.** Engineering in practice — authentication, Flutter, backend.
4. **Open source contribution.** Shows the practice, not just the claim.

**Guidance:**
- Keep the first card an article: it's the most shareable and it states the philosophy.
- Alternate formats (article, project, repo, contribution) so the section doesn't look like a list of the same thing.
- Rotate the middle cards occasionally; keep #1 and the anchor card stable.
