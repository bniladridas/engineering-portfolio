# About

**Short (one sentence):**
Software engineer focused on maintainable systems, developer tooling, and open source.

**Medium (three sentences):**
I'm a software engineer who cares about code that outlasts its authors. I work on maintainable systems, developer tools, and open source, with hands-on experience in authentication, backend services, and Flutter. I write about engineering, I review carefully, and I build in public.

**Long (profile section):**
Software engineer focused on maintainable systems, developer tooling, and open source.

The longer I build software, the less I believe writing code is the difficult part. Keeping software understandable, maintainable, and adaptable is. That belief shows up in everything I make: clear interfaces, predictable structure, documentation written in the same commit as the code, and reviews that are concrete instead of ceremonial.

My work spans authentication systems, backend services, developer tools, and Flutter applications: the layers where small engineering decisions compound. I contribute to open source and I build my own tools in public, because the practice of showing the work keeps the work honest.

I believe the systems that last are the ones the next engineer can understand tomorrow, not just the ones that work today. If that's how you like to build, we'll get along.
