# Banner Spec

**Concept:** Minimal white banner with a subtle engineering grid and Palmshed branding.

**Elements:**
- White background. Nothing else competes with the profile photo.
- A faint 12-column grid, just visible, suggesting structure without shouting.
- A single green accent: the Palmshed mark or a thin rule at the bottom edge.
- Short, centered tagline, set in Inter or IBM Plex Sans. Optional.

**Dimensions:**
- LinkedIn banner: 1584 × 396 px (covers mobile + desktop).
- Export at 2x (3168 × 792) for sharpness.

**Tagline options:**
- "Software that outlasts its authors."
- "Maintainable systems. Developer tools. Open source."

**Text is secondary.** The banner should read as a calm, structured surface — the same aesthetic as the rest of the profile.

See `prompts/` for image prompts and `assets/logos/` for the Palmshed mark.
